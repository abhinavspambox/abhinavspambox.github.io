# Complaint Radar: designing credit-card disputes out of the ombudsman queue

**Signal.** RBI's Integrated Ombudsman Scheme received 13.34 lakh complaints in FY25 (+13.55%). Credit cards became the second-largest category at 17.15%, with 50,811 complaints (+20.04%).

**Product.** An in-app dispute tracker: stage-by-stage status, SLA countdown, document upload, automatic refund of credit balances and proactive updates.

**Metrics.** North star: ombudsman escalations per 10,000 cards. Guardrails: chargeback loss rate, time to first response, CSAT.

**Prototype.** `prototype.html` is a clickable version of the tracker with a 5-task usability test plan (testing not yet run).

Files: `index.html` (dashboard) · `prototype.html` · `data.csv` · `analysis.py`

Source: RBI Annual Report of the Ombudsman Scheme 2024-25; RBI press release 2025-2026/1245.
